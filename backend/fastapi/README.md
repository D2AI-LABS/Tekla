# FastAPI Backend — Universal AI BIM Engine v5.0

This is the Python FastAPI backend that handles AI-driven structural model generation.

## Quick Start

```bash
cd backend/fastapi
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## API Docs
Once running, visit: http://localhost:8000/docs
